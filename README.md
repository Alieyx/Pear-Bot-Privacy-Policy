# Pear - Gizlilik Politikası (Privacy Policy)

**Son Güncelleme:** 28 Ekim 2026

Pear botu, yalnızca temel özelliklerinin çalışması için gereken minimum veriyi işler ve saklar:

* **Toplanan Veriler:** Komutların ve sunucu ayarlarının çalışması için Kullanıcı ID'leri (User ID), Sunucu ID'leri (Guild ID) ve komut içerikleri kaydedilebilir.
* **Verilerin Kullanımı:** Toplanan veriler yalnızca botun işlevlerini yerine getirmek amacıyla kullanılır. Hiçbir veri üçüncü şahıslarla paylaşılmaz veya satılmaz.
* **Veri Güvenliği ve Silinmesi:** Bot sunucudan atıldığında veya kullanıcı talep ettiğinde ilgili veriler veritabanından silinir. Veri silme talepleri için bot geliştiricisiyle Discord üzerinden iletişime geçebilirsiniz.
